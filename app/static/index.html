      Settings

        Welcome to Sermon Studio 👋

        Sermon Studio takes a full recording of a church service, finds the sermon with a local AI, makes a small MP3 and posts it to your WordPress site. Everything runs on this server, so audio doesn't leave it until you publish.

        This short setup (about 5 minutes) asks for:

        1. Storage: the folder where your service recordings are kept.
        2. WordPress: the login used to post sermons.
        3. Discord (optional): a bot that tells you when a sermon is ready and lets you publish from your phone.
        4. Monitoring (optional): watch the recordings folder and analyze new services automatically.

        You can change all of this later under ⚙ Settings.

        Watch for new recordings

        When a new recording appears, it's analyzed automatically and the Discord bot asks you to approve it. Changes take effect right away and are remembered after a restart.

        Storage

        Folders from this server that Docker has made available to the app (set by NAS_PATH and LOCAL_PATH in .env):

            WordPress

            The site the sermons are posted to. Made for The Church Co's WordPress (the “Podcasts” post type). Use a login without two-factor sign-in. The password is stored only on this server.

            Default preacher

            Used when the app can't recognize the preacher's voice with confidence, e.g. a recording made with a different setup or someone it hasn't heard yet. You'll still see a note to check it before publishing.

            📖 Life Group guides

            The Review step can write a discussion guide for each sermon. Point this at a folder with a few of your own past guides (Word, .md or .txt) and the newest two are used as examples of your format and tone. They're read when a guide is written and never copied anywhere. Leave it empty for a generic format.

              Discord bot (optional)

              The bot posts when a sermon is ready, with clips of where it starts and ends, and lets you publish with one tap. It only connects out to Discord, so no ports need to be opened.

              How to create the bot (5 minutes)
              1. In Discord, make a server for yourself if you like (+ → Create My Own) and add a channel such as #sermon-studio.
              2. Turn on User Settings → Advanced → Developer Mode so you can copy IDs.
              3. Open discord.com/developers/applications → New Application → name it “Sermon Studio”.
              4. Installation tab: set Install Link to None and save.
              5. Bot tab:
                • Turn Public Bot off and turn Message Content Intent on, then save.
                • Press Reset Token and copy the token into the box below.
              6. OAuth2 → URL Generator:
                • Tick the scope bot.
                • Tick the permissions View Channels, Send Messages, Attach Files, Embed Links, Read Message History.
                • Open the generated link and add the bot to your server.
              7. Right-click your own name → Copy User ID, and right-click the channel → Copy Channel ID.
